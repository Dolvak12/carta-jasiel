# Love Cards — Para Yasel 💖🌹

This project is a personalized interactive digital letter for **Yasel**, mixing English and Tagalog (Taglish).

## ✨ Features

### 1. Full Personalization
- **Heartfelt Message**: Letter written in Taglish — a mix of English and Tagalog — specifically for Yasel.
- **Custom Photo**: Integration of a personal photo (`image_01.jpg`) with smart loading and error handling.

### 2. Premium Visual Design ("Glassmorphism")
- **Photo Container**: Gradient borders, rotating shiny ring, and soft shadow.
- **Buttons**: "Shine" effect on hover with deep shadows for a modern look.
- **Mixed Particles**: The background rain combines:
    - 🌹 Realistic rose petals.
    - ❤️ Floating hearts.
    - ✨ Golden sparkles.

### 3. Mobile-First Optimization
- **Rain Density**: Adjusted to look fuller and prettier on small screens without affecting performance.
- **"Breathing" Effect**: The card has a soft heartbeat animation on mobile.
- **Responsive Design**: Spacing and sizing adjustments across all elements.

### 4. Robust Music Player
- **Safe YouTube**: Implementation via secure `iframe` (`youtube.com`).
- **Anti-Block**: Automatic fallback system. If the video can't play (due to mobile browser restrictions or in-app browsers like TikTok/WhatsApp), a direct link appears.

## 🚀 How to Use

1. Open `index.html` in your browser.
2. Enjoy the intro animation.
3. Click "Open my letter" to read the message and listen to the music.
